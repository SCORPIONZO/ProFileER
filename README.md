# Психология поведения - Обучающее приложение по профилированию и выялению обмана

## Описание

Это приложение предназначено для изучения различных типов поведения человека и создания психологических профилей. Оно помогает пользователям понять особенности разных типов личностей, их поведенческие особенности, признаки обмана и рекомендации по ведению диалога.

## Особенности

- Просмотр и редактирование психологических профилей
- Экспорт профилей в PDF
- Поиск похожих профилей
- Анализ признаков обмана для разных типов личностей
- Рекомендации по ведению диалога с разными типами личностей
- Telegram-бот для просмотра профилей
- **НОВОЕ**: Веб-приложение для просмотра профилей

## Установка

1. Установите Python 3.x
2. Клонируйте или скачайте проект
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск основного приложения

```bash
python main.py
```

## Запуск веб-приложения

Перейдите в папку веб-приложения:
```bash
cd web_app
pip install -r requirements.txt
python3 run_web_alt.py
```

Затем откройте браузер и перейдите по адресу: `http://127.0.0.1:5001`

## Запуск Telegram-бота

### ВАЖНО: Безопасность токенов
Если вы уже опубликовали токен где-либо (включая использование в чатах с ИИ), вы ДОЛЖНЫ создать нового бота или сбросить токен старого, так как опубликованный токен считается скомпрометированным.

### Вариант 1: Прямой запуск
1. Получите токен у @BotFather в Telegram
2. Установите токен как переменную окружения:
   ```bash
   export BOT_TOKEN="ваш_токен_бота"
   ```
   Или запустите в одной команде:
   ```bash
   BOT_TOKEN="ваш_токен_бота" python bot.py
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```

### Вариант 2: Использование скрипта запуска
1. Запустите скрипт:
   ```bash
   python run_bot.py
   ```
2. Следуйте инструкциям в консоли

### Вариант 3: Использование скрипта настройки
1. Запустите скрипт настройки:
   ```bash
   python setup_bot.py
   ```
2. Следуйте инструкциям в консоли
3. Запустите бота:
   ```bash
   python bot.py
   ```

## Веб-приложение

Новое веб-приложение предоставляет современный интерфейс для просмотра психологических профилей:

- Просмотр всех профилей на главной странице
- Детальный просмотр каждого профиля
- Адаптивный дизайн для просмотра с мобильных устройств
- Поиск по профилям
- Современный UI с использованием Bootstrap

## Telegram-бот

Telegram-бот предоставляет доступ к психологическим профилям через мессенджер. Он поддерживает следующие команды:

- `/start` - начать взаимодействие с ботом
- `/help` - получить справочную информацию
- `/profiles` - получить список всех психологических профилей

## Файловая структура

- `main.py` - основное приложение с графическим интерфейсом
- `web_app/` - веб-приложение на Flask
  - `app.py` - основной файл приложения Flask
  - `run_web.py` - скрипт для запуска веб-приложения
  - `run_web_alt.py` - альтернативный скрипт для запуска веб-приложения (порт 5001)
  - `templates/` - HTML-шаблоны для веб-приложения
  - `requirements.txt` - зависимости для веб-приложения
- `api/` - файлы API для Telegram-бота
- `bot.py` - Telegram-бот для просмотра профилей
- `run_bot.py` - скрипт для запуска бота
- `setup_bot.py` - скрипт для настройки токена
- `test_bot.py` - тесты для бота
- `settings.py` - настройки приложения
- `profiles.json` - данные профилей
- `requirements.txt` - основные зависимости проекта
- `dejavu-fonts-ttf-2.37/` - шрифты для PDF-экспорта
- `BOT_GUIDE.md` - подробное руководство по боту

## Научная основа

Приложение основано на научных исследованиях в области психологии личности, включая:

- Классификации темпераментов (по Гиппократу-Галену)
- Поведенческие особенности расстройств личности по DSM-5
- Исследования в области обнаружения обмана
- Рекомендации по диалогу с разными типами личностей, основанные на психотерапевтических подходах

## Важное примечание

Это обучающее приложение, не предназначенное для клинического использования. Все диагнозы и профилирование должны проводиться квалифицированными специалистами в области психического здоровья.
