# Руководство по запуску Telegram-бота ProFileER

## Подготовка

Прежде чем запустить Telegram-бота, убедитесь, что:
1. У вас есть токен от BotFather в Telegram
2. Установлены все зависимости: `pip install -r requirements.txt`

## Получение токена бота

1. Найдите @BotFather в Telegram
2. Начните чат с ним и используйте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Скопируйте токен, который вы получите после создания

**ВАЖНО: Если вы уже опубликовали токен где-либо (включая использование в чатах с ИИ), вы ДОЛЖНЫ создать нового бота или сбросить токен старого, так как опубликованный токен считается скомпрометированным.**

## Способы запуска бота

### Способ 1: Использование переменной окружения (рекомендуется)

```bash
export BOT_TOKEN="ваш_токен_бота_здесь"
python bot.py
```

Или одной командой:
```bash
BOT_TOKEN="ваш_токен_бота_здесь" python bot.py
```

### Способ 2: Использование встроенного скрипта настройки

```bash
python setup_bot.py
```

Следуйте инструкциям в консоли для настройки токена.

### Способ 3: Редактирование файла напрямую

Откройте файл [bot.py](file:///Volumes/HDD/ProFileER/bot.py) и замените значение переменной `BOT_TOKEN` на ваш токен:

```python
BOT_TOKEN = "ваш_токен_бота_здесь"
```

Затем запустите бота:

```bash
python bot.py
```

## Использование бота

После запуска бота:

1. Найдите вашего бота в Telegram (по имени, которое вы ему дали)
2. Начните чат и введите команду `/start`
3. Используйте команду `/profiles`, чтобы получить список всех психологических профилей
4. Используйте команду `/help`, чтобы получить справочную информацию

## Команды бота

- `/start` — начать взаимодействие с ботом
- `/profiles` — получить список всех психологических профилей
- `/help` — получить справочную информацию

## Особенности бота

- Бот предоставляет доступ ко всей информации, содержащейся в desktop-приложении
- Вся информация структурирована и форматирована для удобного чтения в Telegram
- Бот включает в себя все психологические профили из основного приложения
- Каждый профиль включает описание, черты характера, поведенческие особенности, признаки обмана и рекомендации по диалогу

## Устранение неполадок

### Бот не запускается

Проверьте, установлены ли все зависимости:
```bash
pip install -r requirements.txt
```

### Ошибка: "Ошибка: Необходимо указать токен бота!"

Убедитесь, что вы указали токен бота одним из способов:
- Установив переменную окружения BOT_TOKEN
- Или изменив значение в файле [bot.py](file:///Volumes/HDD/ProFileER/bot.py)

### Ошибка: 'Updater' object has no attribute '_Updater__polling_cleanup_cb'

Эта ошибка связана с совместимостью библиотеки python-telegram-bot. Обновленный код бота уже учитывает эту проблему.

### Ошибка аутентификации

Убедитесь, что токен введен правильно и не содержит лишних символов или пробелов. Если токен был скомпрометирован (опубликован где-либо), создайте нового бота у @BotFather.

### Бот не отвечает

Проверьте подключение к интернету и убедитесь, что Telegram не заблокирован в вашем регионе.

## Безопасность

- Не делитесь токеном бота с другими людьми. Токен дает полный доступ к вашему боту.
- Никогда не публикуйте токен в исходном коде, репозиториях или чатах с ИИ.
- Если токен был скомпрометирован, сбросьте его или создайте нового бота.
