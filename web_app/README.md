# Веб-приложение "Психология поведения"

## Описание

Это веб-приложение является частью проекта ProFileER и предоставляет веб-интерфейс для изучения различных типов поведения человека и создания психологических профилей.

## Особенности

- Просмотр всех психологических профилей на главной странице
- Детальный просмотр каждого профиля
- Поиск по профилям
- Доступ к информации о чертах характера, поведенческих особенностях, признаках обмана и рекомендациях по диалогу

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.x
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите веб-приложение:
   ```bash
   python3 run_web_alt.py
   ```
   Или укажите конкретный порт:
   ```bash
   PORT=5001 python3 run_web.py
   ```

## Использование

1. После запуска откройте браузер и перейдите по адресу: `http://127.0.0.1:5001`
2. Просматривайте список психологических профилей на главной странице
3. Нажмите "Подробнее" для просмотра деталей конкретного профиля
4. Используйте поле поиска для поиска конкретных профилей

## Структура проекта

- `app.py` - основной файл приложения Flask
- `run_web.py` - файл запуска веб-приложения
- `run_web_alt.py` - альтернативный файл запуска с другим портом по умолчанию
- `templates/` - HTML-шаблоны
  - `index.html` - главная страница
  - `profile_detail.html` - страница детального просмотра профиля
- `profiles.json` - данные психологических профилей
- `settings.py` - настройки приложения (в корне проекта)

## API

Приложение также предоставляет JSON API для доступа к данным:

- `GET /api/profiles` - получить все профили
- `GET /api/profile/{id}` - получить профиль по ID
