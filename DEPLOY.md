# Деплой Telegram-бота на Vercel

## Подготовка

1. Установите Vercel CLI:
```bash
npm install -g vercel
```

2. Залогиньтесь в Vercel:
```bash
vercel login
```

## Настройка секретного токена

Перед деплоем необходимо создать секретный токен в интерфейсе Vercel:

1. Зайдите на [vercel.com](https://vercel.com) и войдите в свой аккаунт
2. Перейдите в настройки вашего проекта
3. Перейдите в раздел "Settings" -> "Environment Variables"
4. Добавьте новую переменную с именем `bot_token` и значением вашего токена бота

> **ВАЖНО**: Не храните токен бота в открытом виде в коде или в репозитории!

## Деплой проекта

1. Перейдите в директорию проекта:
```bash
cd /path/to/ProFileER
```

2. Выполните деплой:
```bash
vercel --prod
```

## Настройка вебхука

После успешного деплоя, вам нужно настроить вебхук для вашего бота. Используйте предоставленный скрипт:

```bash
python set_webhook.py
```

И введите URL вашего проекта на Vercel (например, `https://your-project.vercel.app`).

## Структура проекта для Vercel

- `api/index.py` - основной файл обработки вебхуков
- `vercel.json` - конфигурационный файл для Vercel
- `requirements.txt` - зависимости проекта

## Тестирование

После настройки вебхука, ваш бот должен начать обрабатывать сообщения. Проверьте его работу, отправив команду `/start` в Telegram.

## Устранение неполадок

Если у вас возникли проблемы:

1. Проверьте, что токен бота правильно установлен в настройках Vercel
2. Убедитесь, что вебхук настроен на правильный URL
3. Проверьте логи в интерфейсе Vercel для получения дополнительной информации об ошибках
